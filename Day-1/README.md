# Day 1 – Introduction to SKY130 and Open Source Tools

## Topics Covered

- Introduction to SKY130 PDK
- SKY130 PDK layers, devices and libraries
- Open-source EDA tools
- Basic schematic-to-layout flow
- Tool installation and setup
- Creating a simple schematic using Xschem
- Creating a SKY130 layout using Magic
- Layout extraction
- DRC and LVS flow
- Post-layout simulation

## Tools Used

- SKY130 PDK
- Magic
- Xschem
- Netgen
- Ngspice

## Practical Work

A basic inverter design was created starting from schematic entry in Xschem, followed by layout creation in Magic.

The layout was extracted and the extracted netlist was used for LVS comparison with the schematic netlist. Post-layout simulation and basic DRC/LVS verification were also performed.

## Results

The completed schematic, layout, simulation and verification results are documented using the laboratory screenshots included in this folder.
