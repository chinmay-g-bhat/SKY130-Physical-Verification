# Day 3 – DRC Rules and Physical Verification Labs

## Topics Covered

- Silicon manufacturing concepts
- Metal layer rules
- Local interconnect rules
- Device and layout design rules
- Width and spacing rules
- Area and enclosure rules
- Antenna rules
- Density rules
- Electrical Rule Checking (ERC)

## Tools Used

- SKY130 PDK
- Magic
- KLayout

## Practical Work

Multiple physical verification exercises were performed to understand and identify different design-rule violations.

The exercises included layout modifications and verification of width, spacing, area, enclosure, antenna, density and other physical design rules.
